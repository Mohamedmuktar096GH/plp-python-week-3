# Week 3 Assignment on Conditions and Loops

## Files
- `grade_reporter.py`: Loops through a list of student scores to print individual letter grades, pass/fail counts, and the class average.
- `bug_hunt.py`: Fixes three syntax, logic, and type bugs in a `while` loop program so it accurately sums the numbers 1 through 5.

## Reflection
The hardest bug to find was the loop condition `while count < 5` because it did not trigger a Python error message and allowed the program to run smoothly. I knew something was wrong because the program printed `10` instead of the expected `15`, which showed that the loop was stopping before adding the final number `5`.
